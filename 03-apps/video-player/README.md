Feladat: Egészítsd ki a video player appot az alábbi funkciókkal:

- a keresősáv mellett egy gomb is legyen, amire kattintva vagy entert nyomva szintén futtasd a keresést 
- keresés közben jelenjen meg betöltés jelzés, erre elég egy Loading text is
- ha nincs találat, jelenjen meg egy hibaüzenet,
- a kiválasztott videó legyen kiemelve a listában, elég egy körvonal, és háttér vagy egyéb CSS kiemelés
- készítsd egy historyt az eddigi keresőszavakról, egyelőre elég kilogolni konzolra a history tartalmát
