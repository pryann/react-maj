# Feladatok

- A form-ot szedd ki egy külön UserForm komponensbe
- Teszteld újra, hogy midnen rendben van-e  a create és edit estében
- Ha minden oké, akkor készíts  egy InputGroup komponenst, amiben a div-label-input hármas van
- Opcionális, hogy az input group mellett legyen egy InputField komponens, ami csak az Input-ot adja vissza
- A form ezeket a komponenseket használja
